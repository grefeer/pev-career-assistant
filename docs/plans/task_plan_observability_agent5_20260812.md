# Task Plan: Agent 5 可观测性驱动的 4 轮闭环优化方案

## Goal
基于当前仓库事实，设计一个不依赖 Skill 迁移或单点依赖修复的 4 轮可观测性闭环方案。

## Phases
- [x] Phase 1: 读取仓库架构、运行时、配置和测试证据
- [x] Phase 2: 形成监控、停机、聚类、诊断和回归机制
- [x] Phase 3: 推导 3 类最可能根因并排序修复
- [x] Phase 4: 输出独立方案、证据边界和验证标准

## Key Questions
1. 当前运行时已有哪些事件、状态、预算、错误和 SSE 能力可以直接作为观测入口？
2. 如何定义每 3 分钟检查、失败超过 30 立即停止、按工具调用链聚类和 4 轮优化的可执行契约？
3. 哪 3 类根因最可能导致闭环失败，修复顺序如何由观测证据决定？

## Constraints
- 只读分析；不修改源码、配置、数据库迁移或测试实现。
- 不重复“依赖修复”或“Skill 迁移”作为主方案。
- 所有现状判断尽量绑定到仓库路径和测试/代码事实；推断明确标注。
